DifferentialSkeletons Documentation
===================================

DifferentialSkeletons is a PyTorch package for articulated skeletons. It focuses on
forward kinematics, articulated fitting, and skeleton-native priors without requiring
skinned meshes or SMPL-family assets.

This documentation is organized around the core package:

- how to construct and drive models
- how pose representations and body scales behave
- how to load datasets and fit articulated models
- how to train and apply priors
- how to integrate the package into your own code
